# ИИ-агент «Помощник водителю»

## Описание

«Помощник водителю» — это Telegram-бот для водителей, работающих через цифровые платформы. Бот отвечает на частые вопросы о выплатах, блокировках, документах, рейтинге, штрафах, заказах и поддержке.

Пользователь задает вопрос свободным текстом, а бот ищет наиболее подходящий ответ в базе знаний и отправляет короткую инструкцию.

Примеры вопросов:

```text
Мне не пришла выплата
Почему меня заблокировали?
Не приняли права, что делать?
Как поднять рейтинг?
Почему списали деньги?
```

## Как работает бот

1. Пользователь отправляет вопрос в Telegram.
2. Бот очищает и нормализует текст.
3. Вопрос сравнивается с записями из базы знаний.
4. Выбирается наиболее похожая запись.
5. Бот отправляет ответ, тему вопроса и уровень уверенности.
6. Обращение сохраняется в лог для дальнейшей аналитики.

Поиск ответа реализован через `TF-IDF` и `cosine similarity`. Бот сравнивает вопрос пользователя с примерами вопросов, ключевыми словами и ответами из базы знаний.

## Локальная установка и запуск

Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <ссылка-на-репозиторий>
cd driver_assistant_bot_telegram_only
```

Установите зависимости:

```bash
pip install -r requirements.txt
```
Запустите бота:
```bash
python tg_bot.py
```
## Тестирование
Скрипт `run_tests.py` берет вопросы из `test_queries.csv`, определяет тему каждого вопроса и сравнивает ее с ожидаемой.

Результаты сохраняются в файлы:

```text
test_results.csv
test_summary.txt
```

В текущей версии тестирование проведено на 74 запросах по 12 темам. Accuracy на подготовленном тестовом наборе составила 100%.

## Ограничения

Текущая версия является MVP. Он отвечает только на основе подготовленной базы знаний, ссылки в ней -- технические.
Прототип можно использовать как основу для более сложного решения: с подключением реальных данных платформы, GPT-модели, RAG-поиска и аналитического дашборда.
